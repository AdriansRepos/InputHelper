Knihovna sloužící k úpravě vstupů - opravě zadaného jména, příjmení..., 
v případě chyby (zadaní malého počátečního písmene) tato knihovna toto oraví podle českého nastavení na velké písmeno dle gramatické správnosti.
Doplnění metod pro zpracování velkých počátečních písměn víceslovných měst podle pravidel gramatiky.
